# amsyar.github.io

Personal cybersecurity hub built with Jekyll and GitHub Pages.

## Sections

- Home
- CTF Writeups
  - TryHackMe
  - Hack The Box
  - HackSmarter
  - Other CTF
- Projects
- About

## Run locally

Install Ruby + Bundler + Jekyll, then:

```bash
bundle install
bundle exec jekyll serve
```

Open http://localhost:4000

## First things to edit

1. `assets/images/profile.jpg`
2. `_layouts/default.html` social links
3. `_config.yml`
4. `about.md`
5. Delete or replace the example writeup/project.
